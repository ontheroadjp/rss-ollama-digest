# summarize.py

記事の公開日時は RSS の元の値を保存し、新規の保存日時は UTC オフセット付きで記録する（`summarize.py:45-70,253`）。

登録済みフィードを取得し、記事を抽出して Ollama に要約させ、出典と投稿日時を保存する。フィードごとの上限を用い、CLI の `-n` は設定を上書きする。処理済み記事はスキップし、可能な既存記事をフィードに対応付ける。Web 実行時はログと状態を DB に保存する（`summarize.py`）。

記事本文と GUID を保存し、要約から生成した最大3件のタグを JSON として記録する。記事 URL または同一フィードの GUID で処理済みを判定する。Web 実行の停止要求は処理の区切りで確認し、未保存の記事は次回再処理する（`summarize.py`）。
