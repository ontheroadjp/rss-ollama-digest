# 実装仕様

## 処理

`summarize.py` は DB のフィードを走査し、URL のない記事と、URL または同一フィードの GUID が保存済みの記事を除外します。本文を抽出して 200 文字未満をスキップし、先頭 4000 文字を Ollama に送って要約し、要約から最大3件のタグを生成します。抽出本文全体と要約、タグ、GUID、出典を保存します（`summarize.py:39-42,76-88,264-337`）。停止要求は処理の区切りで確認し、保存前の記事は次回再処理します（`summarize.py:91-92,264-265,298-311,321-322`）。

## インターフェース

CLI の `-n` はフィードごとの設定を上書きし、`--ignore-history` は保存済み記事を再処理します（`summarize.py:209-220,281-284`）。Web は記事の検索、フィード・タグ・状態による絞り込み、投稿日時順表示と記事状態の保存、管理画面の設定・DB容量、実行状態・停止・ログを提供します。表示タイムゾーンの既定は Asia/Tokyo です。RSS の公開日時は元の値を保存し、表示時に変換します。タイムゾーン情報のない日時は UTC として扱います（`frontend/app.py:23-45,78-99,142-240`、`summarize.py:45-73`）。
