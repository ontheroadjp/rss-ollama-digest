# 実装仕様

## 処理

`summarize.py` は DB のフィードを走査し、URL のない記事と処理済み記事を除外します。本文を抽出して 200 文字未満をスキップし、先頭 4000 文字を Ollama に送って要約と出典を保存します（`summarize.py:215-305`）。通知先があれば結果を送信します（`summarize.py:175-182,310-316`）。

## インターフェース

CLI の `-n` はフィードごとの設定を上書きし、`--ignore-history` は保存済み記事を再処理します（`summarize.py:189-200,231-257`）。Web は記事の検索・フィード選択と投稿日時順表示、フィード管理、実行状態・ログを提供します（`frontend/app.py:60-166`、`frontend/templates/feeds.html`）。
