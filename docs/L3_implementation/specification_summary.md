# 実装仕様

## 処理

`summarize.py` は DB のフィードを走査し、URL のない記事と処理済み記事を除外します。本文を抽出して 200 文字未満をスキップし、先頭 4000 文字を Ollama に送って要約と出典を保存します（`summarize.py:215-305`）。通知先があれば結果を送信します（`summarize.py:175-182,310-316`）。

## インターフェース

CLI の `-n` はフィードごとの設定を上書きし、`--ignore-history` は保存済み記事を再処理します（`summarize.py:189-200,231-257`）。Web は記事の検索・フィード選択と投稿日時順表示、管理画面の基本設定・フィード設定、実行状態・ログを提供します。表示タイムゾーンの既定は Asia/Tokyo です。RSS の公開日時は元の値を保存し、表示時に変換します。タイムゾーン情報のない日時は UTC として扱います（`frontend/app.py:22-44,78-98,161-199`、`summarize.py:45-70`）。
