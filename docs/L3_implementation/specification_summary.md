# 実装仕様

## 処理

`summarize.py` の `main` は RSS のエントリを走査し、URL がない記事と処理済み記事を除外します。本文を取得・抽出し、200 文字未満をスキップします（`summarize.py:216-263`）。本文先頭 4000 文字を Ollama に送り、結果を保存します（`summarize.py:17,84-109,268-285`）。成功した要約をまとめ、通知先が設定されていれば送信します（`summarize.py:180-187,287-299`）。

## インターフェース

CLI の `-n` / `--limit` は既定 5 件、`--ignore-history` は保存済みの記録を再処理して上書きします（`summarize.py:194-205,276-284`）。Ollama への POST はストリーミング応答を読み取ります（`summarize.py:98-109,148-164`）。
