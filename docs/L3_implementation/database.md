# データベース

SQLite の `articles` は記事 URL を一意にし、要約、モデル、日時、フィード URL とタイトルを保存します。`feeds` は URL、タイトル、任意の取得数を保持します。`runs` と `run_logs` は Web 実行の状態と進捗を保存し、同時実行は一意インデックスで制限します（`database.py:6-32`）。

既存 DB は初期化時に不足する出典・フィード設定の列を追加します。新規 DB はフィード未登録です（`database.py:12-23`）。取得時に RSS 内の既存記事を再発見した場合、欠けている出典を補完します（`summarize.py:241-245`）。
