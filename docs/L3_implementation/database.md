# データベース

SQLite の `articles` は記事 URL を一意にし、抽出本文、フィード内 GUID、状態、要約、モデル、日時、フィード URL とタイトルを保存します。`feeds` は URL、タイトル、任意の取得数を保持し、`settings` は表示タイムゾーンを保持します。`runs` と `run_logs` は Web 実行の状態と進捗を保存し、停止待ちを含む同時実行は一意インデックスで制限します（`database.py:8-51`）。公開日時は RSS の値を保持し、新しい保存日時は UTC オフセットを付けます（`summarize.py:45-73`）。

タグは `tags` と `article_tags` に保存し、記事の状態は `is_read` の 0（未読）、1（興味なし）、2（興味あり）、3（読んだ）で保持します。初期化時に旧 JSON タグ列を関連テーブルに移行して削除します（`database.py:19-35`）。

既存 DB は初期化時に不足する本文・GUID・出典・フィード設定の列を追加しますが、既存記事の本文や GUID は自動取得しません。新規 DB はフィード未登録です（`database.py:12-41`）。取得時に RSS 内の既存記事を再発見した場合、欠けている出典を補完します（`summarize.py:266-271`）。
